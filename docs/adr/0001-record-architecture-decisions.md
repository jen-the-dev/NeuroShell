# 1. Record architecture decisions

Date: 2026-07-10

## Status

Accepted

## Context

NeuroShell is a native macOS product with evolving UI and audio subsystems. Architectural choices should be recorded for maintainers and reviewers.

## Decision

Use ADRs in `docs/adr/` for significant design choices (SwiftUI structure, session model, build automation).

## Consequences

- Reviewers can follow product evolution without relying on commit archaeology.
